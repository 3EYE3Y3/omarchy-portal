# Roadmap

Portal v0.9 prioritizes native desktop understanding over screen streaming. Future candidates, after local acceptance and separate threat-model review:

- phone as microphone;
- phone as webcam;
- opt-in remote desktop;
- secure WAN transport with a replaceable transport interface;
- presence automation;
- reusable scenes;
- opt-in phone sensor APIs;
- platform-independent PAKE/device certificate provisioning;
- Safari-compatible Vision decoder fallback;
- richer app adapters only where reliable structured APIs exist.

No roadmap item is promised, and none is required by the v0.9 local acceptance boundary.
